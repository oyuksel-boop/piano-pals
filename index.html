Keyboard help

Plugging in the Casiotone

  1. Use a cable with Micro-USB on one end (keyboard) and USB-C on the other (tablet). A small OTG adapter also works.
  2. Switch the keyboard on, then open this page in Chrome.
  3. Tap the keyboard button at the top right. If Chrome asks to use MIDI devices, tap Allow.
  4. When the light turns green, the app can hear every key.

The keyboard makes its own sound, so the tablet stays quiet while you play. Without a cable you can still use the keys on screen.

Progress is saved on this tablet, separately for each girl.
